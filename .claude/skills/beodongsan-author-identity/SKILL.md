# 브동산 — 작성자 아이덴티티 체계 (2026.09.28 확정)

Paul이 확정한 브동산 콘텐츠의 "누가 쓰는가" 표기 규칙. 새 카테고리를 만들거나 포스팅의 byline(아바타+작성자명)을 정할 때 이 규칙을 따른다.

## 기본 원칙
- **홈페이지/블로그 이름**: 브동산 (변경 없음, 사이트 전체 브랜드).
- **아바타(byline `.avatar` 원형)는 콘텐츠 도메인과 무관하게 항상 "브" 하나로 유지한다.** 이건 사이트 시그니처이며, 어떤 카테고리·작성자든 절대 바꾸지 않는다. (2026.09.28: 한때 "서당댁" 카테고리 전용으로 아바타를 "서"로 바꿔봤으나, Paul이 "브 동그라미는 시그니처로 유지"라고 명확히 되돌렸다 — 다시 실험하지 않는다.)
- **작성자명(byline `.who` 텍스트)만 콘텐츠 주체에 따라 구분한다**:
  - **"서당개"** — Paul(브동산 운영자 본인)이 직접 쓰는 콘텐츠. 청약·분양(`realestate`), 브랜드이야기(`brand`) 등 기존 모든 콘텐츠 도메인이 해당.
  - **"서당댁"** — Paul의 배우자 시점/보이스로 쓰는 콘텐츠. 현재는 "베트남 호치민 이야기"(`vietnam`) 카테고리가 해당. 이 페르소나의 글쓰기 방식(말투·구조)은 `beodongsan-vietnam-vlog-post` 스킬 참고.

## 마크업
```html
<div class="byline">
  <span class="avatar">브</span>
  <span class="who">서당개</span>  <!-- 또는 서당댁 -->
  <span class="dot">·</span>
  <span class="when">YYYY. M. D</span>
  <span class="tag">{카테고리명} No.N</span>
</div>
```

## 새 카테고리를 만들 때
1. 이 카테고리의 글을 누구 목소리로 쓸지 먼저 Paul에게 확인한다 — 임의로 "서당개"나 "서당댁" 중 하나를 골라 쓰지 않는다.
2. 기존 두 이름 중 하나를 재사용할 수도 있고, Paul이 새 닉네임을 정할 수도 있다. 어느 쪽이든 아바타는 여전히 "브"로 고정한다.

## 소급 반영 여부 (미확정, 2026.09.28 기준)
지금까지 발행된 청약·분양/브랜드이야기 포스팅은 아직 작성자명이 "브동산"으로 돼 있다(이 체계가 확정되기 전에 만들어짐). 이걸 전부 "서당개"로 바꿀지는 Paul이 아직 결정하지 않았다 — **먼저 물어보고, 원하면 몇 개가 있는지 확인해 한 번에 정리한다.** 임의로 소급 수정하지 않는다.

- 호치민 이야기(서당댁) 콘텐츠를 실제로 어떻게 쓰는지는 `beodongsan-vietnam-vlog-post` 스킬 참고.
