# 브동산 — 디자인 가이드라인

Paul의 기본 취향과 브동산 프로젝트의 확정된 시각 규칙. 상세 결정 과정·기각된 시안은 `claude/design-guideline.md`, `claude/handoff-master.md`(2번 섹션) 참고.

## 디자인 철학
**애플처럼 심플하고 색을 많이 쓰지 않는 세련된 디자인**이 모든 디자인 결정의 기본 기준. 로고처럼 되돌리기 어려운 결정은 여러 방향을 나란히 비교한 뒤 확정한다.

## 컬러 팔레트 (화이트/블랙 모노톤, 확정)
- 배경 흰색 `#FFFFFF`, 텍스트 검정 `#111111`, 보조 회색 `#555555`/`#8A8A8A`, 구분선 연회색 `#E3E3E3`.
- **컬러는 이미지 자료(사진)에만 허용된다.** 로고·차트·버튼·배지 등 그 외 UI 요소는 예외 없이 흑백만 사용한다. (예: 부동산 포스팅의 지도 핀은 사진 자산이라 컬러 유지 가능하지만, 같은 포스팅의 레이더 차트는 SVG UI 요소라 흑백만 — 실선/파선/점선과 굵기로 구분.)

## 타이포그래피
나눔고딕(Nanum Gothic). 나눔바른고딕 요청이 있었으나 구글 폰트에 없어 대체 중 — 실제 폰트 파일을 받으면 `@font-face` data URI로 교체 가능.

## BI(로고) — 최종 확정, 재검토 금지
**순수 워드마크, 장식 없음.** "브"(브랜드)=나눔고딕 굵게(800, 검정 `#111111`), "동산"(부동산)=가볍게(400, 회색 `#555555`) — 무게 차이로 결합을 표현. **밑줄·포인트 컬러·원형 뱃지 등 어떤 장식도 없다** — 네이비 밑줄, 원형 뱃지 버전 모두 검토 후 최종 기각됐으니 다시 꺼내지 않는다. 로고 캔버스(기각안 포함): https://claude.ai/code/artifact/a7d9d1b4-4ea3-4f4a-b4d2-baa36c6612c2

## 포스팅 레이아웃 컨벤션
- 상단 바(`.top-eyebrow`): 왼쪽 로고(`브동산`, 클릭 시 홈 `https://brandongsan.com/`), 오른쪽 "☰ 목록" 버튼(흑백 아웃라인 pill, 카테고리 페이지로 연결) — `display:flex; justify-content:space-between`.
- 순서: 제목 → 아바타+작성자+날짜+시리즈번호 → 구분선 → 커버 이미지(실사) → 본문(라벨:값 리스트, 얇은 표, 굵은 글씨 강조 불릿, 섹션 사이 실사 이미지) → 하단 AD 상담카드(흑백, "AD·광고" 배지) → **"관련 포스팅" 섹션(`section#related`)** → 푸터.
- **"관련 포스팅" 섹션**: `<h2>{카테고리명}의 다른 포스팅</h2>` → 같은 카테고리 최신순 최대 5개를 `.related-item` 카드(제목+시리즈번호 태그)로 나열 → "{카테고리명} 목록 전체보기" 버튼(`.btn-list`). 다른 포스팅이 없으면 `.related-empty` 안내 문구. **이 목록은 실시간 로드가 아니라 발행 시점에 HTML에 직접 하드코딩** — 새 포스팅 추가나 발행 순서 변경 시 같은 카테고리 기존 포스팅에도 소급 갱신해야 한다.
- 사진은 `.photo-block` 클래스(테두리 1px 연회색, 하단 작은 회색 출처 캡션)로 통일. 콘텐츠 도메인(부동산/브랜드) 무관하게 모든 포스팅에 이 스타일을 적용한다.

## 홈페이지 대문(히어로)
라인아트 일러스트 등 이미지 없이 **텍스트 중심**으로 확정 — 이미지 도입 시안은 폐기됐으니 다시 꺼내지 않는다.

## 원칙
디자인/BI 규칙이 바뀌면 이미 발행된 콘텐츠에도 즉시 소급 반영을 검토한다. 단, 원본에 없던 세부 데이터를 새로 지어내야 하는 경우(예: 부동산 포스팅의 교통환경 세부표)라면 소급을 포기하고 신규 콘텐츠부터만 적용하는 것이 더 정직한 선택일 수 있다.
