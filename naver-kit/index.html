폰에서 복사·저장하며 올리는 용도
앱에서 올리는 법 (6단계)
  1. 글을 열고 제목 복사 → 새 글 제목에 붙여넣기
  2. 태그 복사 → 태그 칸에 붙여넣기
  3. 본문 전체 복사 후 본문에 붙여넣기 (사진 자리는 【사진 번호】 줄로 표시)
  4. 이미지 전체 사진첩에 저장 (공유창에서 '이미지 저장')
  5. 에디터에서 【사진 번호】 줄을 찾아 그 자리에서 사진 버튼 → 같은 번호 파일 선택 (자리표시 줄은 지우기)
  6. 카테고리·대표이미지 확인 후 발행
