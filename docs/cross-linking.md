# 교차링크 기준 — 웹사이트·네이버 블로그·유튜브·네이버 클립 (2026.11.28 Paul)

모든 길이 **브동산 웹사이트**(애드센스·쿠팡·계산기 수익이 나는 곳)로 모이게 하되, 각 채널 안에서 할 일을 먼저 한다.
링크는 글·영상마다 1~2개만. 같은 링크를 댓글마다 반복하지 않는다. 네이버 글에는 쿠팡 링크를 넣지 않는다(쇼핑커넥트만).

| 출발 | 도착 | 방법 | 누가 |
|---|---|---|---|
| 네이버 클립 | 같은 주제 네이버 블로그 글 | 클립 '정보 스티커 → 블로그' | 어사이드 |
| 네이버 블로그 | 웹사이트 해당 글 | 결론의 홈페이지 링크 문장(원고에 이미 있음) | 원고 |
| 네이버 블로그(청약) | 당첨 자금 계산기 | 결론에 `https://www.brandongsan.com/calc/cash-plan.html?apt=<slug>` 한 줄 | 원고 |
| 네이버 블로그(도시이야기) | 유튜브 본편 | '영상으로 보기' 칸에 글쓰기 창 '링크' 버튼으로 영상 카드(블로그 안에서 재생). 영상은 하나만 | 원고 자리 + 어사이드 |
| 유튜브 쇼츠 | 같은 채널 긴 영상 | 스튜디오 '관련 동영상'(쇼츠 설명란 링크는 눌리지 않음). 도시이야기 쇼츠 → 그 도시 본편, 청약 쇼츠 → 같은 권역 최신 미분양 랭킹 본편(없으면 채널 최신 가로 영상) | 어사이드 |
| 유튜브 긴 영상 | 웹사이트 해당 글 | 설명란 첫 줄 근처에 사이트 글 주소(긴 영상은 눌림) | 설명 txt |
| 유튜브 채널 | 웹사이트 | 채널 프로필 링크에 brandongsan.com | Paul 1회 |
| 웹사이트 글 | 유튜브 | '영상으로 보기'(youtube-nocookie 임베드, `scripts/embed_video.py`) | 예약 회차 |
| 웹사이트 홈·소개 | 네이버 블로그·유튜브 채널 | 바닥 채널 링크(글 본문에는 네이버 링크 넣지 않음) | 채널 주소 받으면 |

## 업로드 주소 받기
- 어사이드가 올린 뒤 콘텐츠 폴더의 업로드 주소 파일에 적는다: 청약 `06_업로드주소.txt`, 도시이야기 `업로드주소.txt`(유튜브 본편·쇼츠, 네이버 글, 클립).
- 예약 회차는 시작할 때 최근 14일 폴더의 이 파일을 읽어, 유튜브 주소가 있고 사이트 글에 아직 `<!-- video-embed:start -->`가 없으면 `python3 scripts/embed_video.py <slug> <주소...>`로 넣고 그 회차 push에 포함한다.
