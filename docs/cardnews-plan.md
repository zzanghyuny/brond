# 브동산 카드뉴스 기획 (2026.11.28 Paul 확정)

청약 언박싱 · 미분양 선착순 랭킹 · 랭킹 쇼츠 · 도시이야기는 **카드뉴스까지** 만든다. 콘텐츠 한 편 → 카드뉴스 한 묶음. 숫자·문구는 그 콘텐츠의 사이트 글·영상 데이터와 똑같이 쓰고 새로 계산하지 않는다.

## 공통 규칙
- 크기 1080×1350(4:5), 최대 10장(유튜브 게시물 한도). 첫 묶음을 클립·유튜브에 올려 잘림을 확인하고, 문제가 있으면 9:16판을 함께 만든다.
- 디자인: 흑백 + 황동 포인트 `#C8A45C`, 쇼츠와 같은 고딕 글꼴. 매 장 오른쪽 위 쪽 번호(`3/8`), 아래 브동산 워드마크. 사진 출처는 그 장 아래 작은 회색 글씨(공식 분양 홈페이지 CG·Pexels·Google Earth 등). Google Earth 화면은 표지에 쓰지 않는다.
- 예상 프리미엄은 금액 먼저, 판정은 괄호(`+5,960만 (저평가)`). 과장·수익 약속 문구 금지. 투자 권유 아님 문구는 마지막 장에.
- 마지막 장의 다음 행동은 하나만(사이트 글·계산기·줍줍찬스·본편 영상 중 하나).
- 올리는 곳: **네이버 클립 게시물**(수익화 대상, '정보 스티커 → 블로그'로 같은 주제 네이버 글), **유튜브 이미지 게시물**(노출·구독용, 광고 수익 없음), 인스타그램(계정이 생기면 같은 파일).
- 전달: 각 콘텐츠의 드라이브 폴더에 `07_카드뉴스/01.png …`와 `07_카드뉴스-캡션.txt`(캡션 3줄 + 해시태그 + 클립·유튜브 올릴 때 메모). 도시이야기·랭킹 쇼츠 폴더는 번호 없이 `카드뉴스/`.

## ① 청약 언박싱 — 1분 총정리 쇼츠와 같은 구성 (8~10장)
기준: 쇼츠 ③ '1분 총정리'(`scripts/shorts/make_brief.py`, `brief/<키>.json`)와 **같은 데이터·같은 순서**. 영상 장면을 카드로 옮긴다.
1. **표지**: 위성지도 위 단지 위치 표시(또는 공식 조감도) + **큰 단지명** + 관심 문구 **"이 단지, 적정가는 얼마?"** + "청약 전 이것만 보세요 — 1분 총정리" + 체크리스트 5줄(당첨되면 현금 얼마? / 예상프리미엄 얼마? / 어떤 동네인가? / 단지·평면은 어떤가? / 모집공고 속 유의사항은?)
2. **01 현금**: 납부 일정별 필요 현금(계약 후 한 달 · 중도금 · 입주 때), 분양가와 계약금·중도금·잔금 비율 막대
3. **02 예상프리미엄**: 비교단지 2곳 시세 → 평점·연령 보정 → 브동산 적정가 → 분양가와 차이. 결론 숫자를 크게(판정 괄호)
4. **03 입지**: 거리 지도(단지·역·터미널·학교) + 거리 3줄
5. **04 단지·평면**: 공식 배치도 위 배치 형태 표시 + 커뮤니티 칩 + 주력 평면 베이·알파룸 표시
6. **05 유의사항 — 가격 조건**: 공고문 원문 인용 + 쉬운 말 풀이(중도금 무이자 조건, 분양조건 변경 소급 등)
7. **05 유의사항 — 주변·단지 안 시설**: 위성·배치도 위 번호 표시 + 목록(방음벽·도로·산업단지·소음·빛공해·정압기 등). 많으면 2장으로 나눈다
8. **요약**: 5줄 요약 + 청약 일정(특공·1순위·발표) + 다음 행동 "당첨되면 필요한 돈 → 브동산 계산기(`/calc/cash-plan.html?apt=<slug>`)" + 출처·투자 권유 아님

## ② 미분양 선착순 랭킹 — "지금 줍기 좋은 곳 TOP5" (10장)
1. **표지**: "○○권 미분양, 청약통장 없이 고르는 TOP5" + 1위 단지 조감도
2. **읽는 법**: 선착순 동·호 지정이란, 예상 프리미엄 = 브동산 적정가 − 분양가
3~7. **1~5위**: 한 장에 한 단지 — 조감도, 지역·세대수, 분양가, 예상 프리미엄(판정), 확인된 장점 1줄
8. **지난 회차 대비**: 새로 들어온 단지·빠진 단지
9. **실거주 체크**: 할인·혜택 조건, 입주 시기, 계약 전 확인할 것
10. **다음 행동**: 줍줍찬스에서 전국 단지 전체 보기 + 출처·투자 권유 아님
- 재료: `scripts/firstcome/regions/<RID>.json`과 회차 이미지. 권역 회차마다 한 묶음.

## ③ 랭킹 쇼츠 — "1위 맞혀 보세요" (7장)
1. **표지 질문**: "전국에서 84㎡가 가장 비싼 동네는?" 같은 질문형
2. **10~4위**: 한 장에 목록
3~5. **3위·2위·1위**: 한 장씩, 동네 사진이나 지도 + 숫자
6. **기준·출처**: 데이터 출처와 기준일
7. **다음 행동**: "우리 동네는 몇 위? 다른 랭킹 보기"
- 재료: 영상과 같은 rank JSON(`scripts/shorts/rank/`). 하루 3편 중 **반응 좋은 주제 1편만** 카드뉴스로 만든다.

## ④ 도시이야기 — "이 도시는 왜 이런 모양일까" (8장)
1. **표지**: 드론 실사 + 질문형 제목(예: "브라질리아는 왜 비행기 모양일까")
2. **숫자로**: 면적(서울의 몇 배), 인구, 생긴 해
3~5. **이렇게 된 이유 3가지**: 한 장에 하나, 지도·위성 그림과 함께
6. **꼭 보는 장면 4곳**: 2×2 사진
7. **사람들이 사는 곳의 이동**: 주거 이동 개략도
8. **다음 행동**: "본편 영상으로 보기"(유튜브·네이버 클립 롱폼) + 출처
- 재료: `scripts/dosi/epN-<도시>/`의 대본·지도·사진. 표지에 Google Earth 화면은 쓰지 않는다.

## 만드는 방법 (구현 예정)
- 생성기 `scripts/cardnews/`에 네 가지 틀(청약·미분양 랭킹·랭킹 쇼츠·도시)을 둔다. 청약 틀은 `brief/<키>.json`을 그대로 읽는다.
- 각 작업 절차의 마지막 단계에 붙인다: 청약 예약 회차(`docs/cheongyak-scheduled-run.md`), 미분양 권역 회차(`docs/firstcome-runbook.md`), 랭킹 쇼츠 묶음, 도시이야기(`scripts/dosi/RUNBOOK.md`).
- 만든 카드는 모두 Read로 열어 글자 잘림·겹침을 확인한다.
- 첫 샘플: 트리븐 가흥(청약) · 04 브라질리아(도시) → Paul 확인 후 나머지 틀과 자동화.
