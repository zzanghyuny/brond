# 네이버 발행본 — 모바일(폰) 폭 기준 (2026.11.14, Paul 결정, 항상 적용)

네이버 블로그 독자 대부분이 폰으로 본다. 이미지는 폰에서 약 390px 폭으로 줄어 보이므로, **PC 기준으로 만든 크기·글씨는 쓰지 않는다.** `docs/naver-sample/`의 PC 형식 샘플과 충돌하면 이 문서가 이긴다(섹션 구성·문체·순서는 샘플 그대로, 크기·배치만 모바일 기준).

## 1. 이미지(직접 만드는 차트·표 이미지)
- 캔버스 폭 **1000px**. 이미지 안 모든 글씨는 **28px 이상**(폰에서 약 11px), 값 숫자 32px 이상, 제목 36px 이상. 개략도 안내 박스·범례만 26px까지 허용.
- 생성은 반드시 `scripts/beodongsan/make_naver_charts.py`(기본 `mobile=True`): `chart_a`(평점 비교) · `chart_b`(적정가격·분양가 + 예상 프리미엄 박스) · `chart_map`(개략도 1000×1000, 라벨 개체 최대 8개, 안내문 3줄 이내) · `chart_c`(세로 일정 타임라인). 형태는 승인 샘플과 같고 항목 이름을 막대 위에 두는 점만 다르다.
- 만든 PNG는 반드시 390px 폭으로 줄여서(`PIL resize`) 열어 보고 가장 작은 글씨가 읽히는지, 겹침이 없는지 확인한다. 한 장 ≤ 450KB.
- 공식 사진(조감도·배치도·평면도 등)은 가로 ≤ 1000px, ≤ 400KB(JPEG q80~85)로 줄여 쓴다. 평면도처럼 글씨가 있는 이미지는 1000px 폭에서 읽히는지 확인한다.

## 2. 표
- 열 4개 이하, 셀은 짧게(두 줄은 `<br>`). 5열 이상이거나 폰에서 줄바꿈이 심하면 **표 대신 이미지로** 만든다(폰 네이버 앱 에디터는 표 붙여넣기가 불안정하다).
- 표 아래에는 굵은 요약 문장을 둔다(샘플 규칙 그대로).

## 3. 글(문단)
- 한 문단 2~3문장. 문단·이미지 사이 빈 문단 한 줄(샘플 규칙). 한 줄 25자 안팎에서 자연스럽게 끊기도록 짧은 문장을 쓴다.
- 굵은 핵심 수치 문장(적정가격·분양가·예상 프리미엄)은 섹션 1, 평점표 아래, 가격표 아래에 반드시. 이미지 캡션은 작은 회색 non-bold, 번호는 섹션 5에서만.

## 4. 폰으로 발행하는 방법 (naver-kit)
- 각 글마다 `naver-kit/<slug>.html` 페이지를 만든다(`scripts/naver_kit.py <slug>`). 폰에서 이 페이지를 열면 글이 **발행 순서대로 블록**으로 나뉘어 있다: 제목·태그(복사 버튼), 문단별 복사 버튼, 이미지별 저장 버튼(차트·표 이미지 포함). 표는 이미지 블록으로 바뀌어 있다.
- 사용 순서: ① 폰 크롬/사파리에서 kit 페이지 열기 → ② 블록 순서대로 "복사" → 네이버 블로그 앱에서 붙여넣기 ③ 이미지 블록은 "저장" 후 앱의 사진 추가로 삽입 ④ 제목·카테고리·태그 입력 후 발행.
- kit 페이지는 `noindex`이고 사이트 목록에 노출하지 않는다.

## 5. 체크리스트(전달 전)
1. 모든 이미지가 1000px 폭이고 390px 미리보기에서 글씨가 읽힌다. 2. 표는 4열 이하 또는 이미지. 3. 문단 2~3문장. 4. 굵은 3수치 문장 위치. 5. kit 페이지 생성·열림 확인.
