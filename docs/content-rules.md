# 브동산 콘텐츠 공통 규칙 (Claude Code · Aside 공용)

Claude Code 전용 규칙은 `CLAUDE.md`와 `.claude/skills/`에 그대로 두고, 여기에는 **누가 읽어도 적용할 수 있는 공통 규칙**만 정리한다.

## 1. 사실과 출처
- 수치·사실(가격, 세대수, 일정, 경쟁률)은 지어내지 않는다. 확인하지 못한 항목은 "확인하지 못했다"고 쓴다.
- 분양가는 입주자모집공고문(청약홈) 기준. 언론·블로그 예상치는 "예상(비공식)"으로만 인용한다.
- 시세는 같은 크기 타입끼리 **총액**으로만 비교한다. 평당가·㎡당가는 어디에도 노출하지 않는다.
- 수치는 자료 시점 기준이며 바뀔 수 있다는 면책 문구를 유지한다. "투자 권유·청약/매수 대행이 아님"을 반드시 밝힌다.

## 2. 부동산 포스팅 고정 5단계
1 핵심요약(적정가·예상 프리미엄) → 2 입지분석 → 3 상품분석 → 4 공급분석(Supply Check) → 5 결론. 체크리스트 섹션은 넣지 않는다.

## 3. 적정가 산출("브동산 모형") 요약
- 비교단지 2곳 → 같은 크기(전용 84㎡ 우선, 없으면 59㎡) 최근 실거래 기준가 → 평점 보정 × 연령 보정 → 두 보정가격의 **평균 = 적정가**.
- 평점(100): 입지 40(교통 20 + 주거편의 10 + 교육 10) + 브랜드 20 + 상품성 40. 수도권·광역시는 지하철 중심, 기타지방(세종 포함)은 터미널·KTX + 배정초 + 중심상권 대체.
- 평점보정 = 1 + (SITE−비교단지 점수차 × 0.01), 최대 ±20%. 연령보정은 SITE **공고상 입주예정월** 기준(수도권·광역시 상한 1.2, 기타지방 상한 1.3).
- 예상 프리미엄 = 적정가 − 실제분양가(84㎡ 타입 세대수 가중평균). 퍼센트는 실제분양가 대비.
- 분양가 공개 전에는 프리미엄을 쓰지 않고 "적정가 + 분양가는 공고 후 업데이트"로 올린다.
- 상세 배점표·공식은 `CLAUDE.md`·`claude/handoff-master.md`와 realestate-post 스킬을 따른다.

## 4. 문체
- 사이트 글: 평서형 "-다/-였다/-이다/-된다". 면책 문구까지 동일.
- 네이버 글: 사이트 글과 같은 사실을 쓰되 문장 순서·서술 방식을 새로 쓴다(단순 동의어 치환 금지).
- 이모지·과장·단정적 투자 권유 금지(한줄평의 "넣어야 한다" 톤은 프리미엄이 뚜렷한 플러스일 때만).

## 5. 한줄평 톤 (네이버 결론)
- 프리미엄이 뚜렷한 플러스 → 청약 자격이 되면 넣어야 한다는 단정 톤.
- 미약하거나 무피·약한 마피 → 투자로는 애매, 실거주 추천 + 어울리는 가족 형태 한 단어.
- 마피 폭이 큰 경우 → 신중. 시장 변곡점·판촉조건을 보며 판단, 꼭 살아야 하는 사람은 가능.
- 분양예정(분양가 미공개) → 분양가 공개 후 프리미엄으로 판단하자는 톤.

## 6. 이미지
- 공식 분양 홈페이지(또는 시행·시공사 공식 자료)의 조감도·위치도·배치도·동호수배치도·**타입별 평면도 전부**를 별도 파일로 저장한다(base64 인라인 금지).
- 합성 이미지는 조감도 부분만 잘라 커버로 쓴다. 커버는 구도를 훼손하는 크롭 금지.
- 위치 개략도는 실제 지도 캡처 금지, 브동산 자체 제작 흑백 SVG(SITE=검정 ■, 비교단지=회색 테두리 □, 배정초=검정 점선 □). 네이버용은 이를 PNG(`chart-map.png`)로 캡처해 사용한다.
- 출처 불명 사이트·언론 워터마크 이미지는 캡션에 출처를 밝히거나 쓰지 않는다.

## 7. 디자인
- 사이트 UI는 흑백 모노톤(애플 스타일). 사진만 컬러 허용. 로고·BI는 확정된 것만 사용.

## 8. 카테고리·번호
- 부동산 글은 `청약 언박싱 No.NNN` 연번을 쓴다(현재 최신 번호는 `posts-data.js` 참고). 브랜드 글 `브랜드 언박싱`, 호치민 글 `호치민 이야기` 번호는 각자 별도.

## 9. 공간이야기·브랜드이야기 서두 (2026-11-04)
- 공간이야기와 브랜드이야기 글은 핵심요약(요약표·글머리표)으로 시작하지 않는다. 서두는 한두 줄의 궁금증형 문장으로, 업무 문서가 아니라 일상 대화처럼 쓴다.
- 핵심요약은 부동산이야기(단지 글)에만 쓴다. 핵심요약이 없는 글의 번호 섹션은 1번부터 시작한다.
- posts-data.js의 preview도 같은 서두 문장을 쓴다.
