# 브동산 콘텐츠 지도 — 종류별 원본과 파생 콘텐츠 (2026.11.28 기준, 카드뉴스 추가)

브동산의 모든 콘텐츠는 **웹사이트 글(원본)** 하나에서 출발해 네이버·유튜브·클립·계산기로 파생된다. 수익은 웹사이트(애드센스·쿠팡·계산기)에 모이고, 나머지 채널은 그 채널 안의 수익(애드포스트·쇼핑커넥트·클립 인센티브·유튜브 광고)을 내면서 웹사이트로 사람을 보낸다. 세부 규칙은 각 줄의 기준 문서가 이긴다.

## 2. 파생 흐름 (모든 길은 웹사이트로)

```
              ┌──────── 웹사이트 글 (원본·수익: 애드센스·쿠팡·계산기) ◀─────────┐
              │            │ '영상으로 보기'(유튜브 임베드)                         │
              ▼            ▼                                                       │
   네이버 블로그 원고   유튜브 (쇼츠·본편)  ──관련 동영상──▶ 긴 영상 ──설명란 링크──┤
   (애드포스트·쇼핑커넥트)                                                          │
        ▲  결론 링크 ───────────────────────────────────────────────────────────────┘
        │
   네이버 클립 (쇼츠·롱폼·카드뉴스 게시물, 클립 인센티브) ──정보 스티커──▶ 블로그 글
   유튜브 이미지 게시물(카드뉴스) · 인스타그램(계정 생기면) ──▶ 노출·구독
```

- 링크는 글·영상마다 1~2개, 네이버 글에 쿠팡 금지, 사이트 글을 네이버에 그대로 복사 금지(구성 절반 이상 다르게).
- 세부: `docs/cross-linking.md`.

| 랭킹 쇼츠 | (없음) | 브동산 랭킹 쇼츠/`YYYY-MM-DD 랭킹 쇼츠 3편` | 00 읽어주세요 · NN 영상·썸네일 · 카드뉴스(1편) |
| 도시이야기 | 도시 글·지도·사진 | 브동산 도시이야기/`NN 도시명` | README(교차링크 포함) · 네이버원고 · 본편·쇼츠 2 · 썸네일 3 · 설명 txt 3 · credits · 업로드주소 · 카드뉴스 |

어사이드는 게시를 마치면 폴더 이름 앞에 `[게시완료]`를 붙이고, 업로드주소 파일에 올린 주소를 적는다 → 다음 회차가 사이트 글에 영상을 넣는다.

## 4. 채널별 수익 구조

| 채널 | 수익 | 브동산에서 하는 일 |
|---|---|---|
| 웹사이트 | 애드센스, 쿠팡 파트너스(청약·공간 글 카드), 줍줍찬스 상담사 카드 | 모든 글의 원본, 계산기, 홈 대문 |
| 네이버 블로그 | 애드포스트, 쇼핑커넥트(원고 하단 3칸) | 원고를 사이트와 다르게, 결론에 사이트·계산기 링크 |
| 유튜브 | 쇼츠·긴 영상 광고 수익(이미지 게시물은 광고 수익 제외) | 쇼츠 관련 동영상 → 긴 영상, 긴 영상 설명란 → 사이트 |
| 네이버 클립 | 광고 인센티브(영상·카드뉴스 게시물), 크리에이터 프로그램(월 동영상 10건 또는 게시물 15건 미션), 텍스트·이미지 게시물도 수익화 대상(2026) | 쇼츠·본편 롱폼 업로드, 블로그 정보 스티커, 'AI 활용' 설정 |
