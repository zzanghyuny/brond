**원칙: 긴 문장 대신 표와 짧은 문장.** 비교·수치·조건은 표로, 설명은 문단당 1~2문장으로 짧게 요약한다. 4열 이하 표만 쓴다(`table style="width:100%;border-collapse:collapse;word-break:keep-all"`, 셀 `border:1px solid #ccc;padding:6px;text-align:left`).

순서(h2는 짧게, 부제 없이):
0. **맨 첫 문단 = 요약문**(합니다체 2~3문장): 지역+단지명, 세대수, 84㎡ 가중평균 분양가, 브동산 분석 적정가격, 1순위 날짜. 그다음 바이라인 `브동산 청약 언박싱 · YYYY.MM.DD` (h1 제목은 본문에 넣지 않는다 — 네이버 제목 칸에 입력).
1. `1. 결론부터`
   - 청약 전에 먼저 볼 점 한 문장(실용 조언).
   - 표 `구분 | 가격`: 브동산 분석 적정가격 / 실제 분양가 · 84㎡ 가중평균 / 예상 프리미엄 · 모형 차이. (스탯 박스 대신)
   - 굵은 3수치 문장 + "적정가 대비 약 N% 고(저)평가" 한 문장.
   - 조감도(캡션: 출처 · 단지명 조감도 (CG)) + 개요 표 `항목 | 공고 내용`: 위치 / 규모 / 분양(특별·일반) / 입주 / 시공 / 규제.
2. `2. 왜 이 가격이 나왔을까`
   - 비교단지 선정 이유 1~2문장, 예정 시설·학교는 "예정·확인 필요"로 1문장.
   - 표 `선정 비교단지 | 동일 전용면적 기준가격` (단지명 + (준공 YYYY.MM · 세대수) | KB 면적 · 가격 · 조회일).
   - h3 `입지·브랜드·상품성 평점` + 표 `항목 | SITE | 비교1 | 비교2` (입지 x/40, 브랜드 x/20, 상품성 x/40, 합계) + 굵은 한 줄 `종합평점 N점 · 비교단지 N점 / N점.`
   - h3 `보정가격과 실제 분양가` + 표 `비교단지 | KB 일반가 → 보정가격` (비교1, 비교2, 브동산 적정가격, 실제 분양가, 예상 프리미엄 · 적정가 대비 약 N%).
   - chart-b(적정가격·분양가 막대, 황동) 1장. **평점 막대(chart-a)·위치 개략도(chart-map)는 넣지 않는다.**
   - 가정·한계는 짧은 문장 몇 개(연식 보정 기준, 미개통 역 미가산, 중립 점수 항목 등)와 출처 한 줄.
3. `3. 브동산 한줄평` — 한 문장(실용 조언형).
4. `4. 지역 최근 분양단지` — 표 `단지 | 공고 기준 비교`(공고 월 · 타입별 최고 공급금액) + 기준 설명 한 문장 + 비교 공고 자료 링크.
5. `5. 분양 사이트 자료로 한 번에 보기`
   - 공식 입지환경 → 공식 청약 일정 이미지(캡션: 출처 · 종류).
   - h3 `정리` + 표 `타입 | 세대 | 공급가(만원)` + 확장비·납부 비율 한 문장 + 공식 세대안내 링크.
   - 단지배치도 → 동호수 배치도 → 타입별 평면도(캡션: 종류 · 사업주체 공식 분양 홈페이지). 없으면 "미게시".
6. `6. 결론 — 접수 일정`
   - 표 `구분 | 날짜` (특별공급, 1순위, 2순위, 당첨자 발표, 정당계약).
   - 일정 한 문장 + 해당지역·기타지역 범위와 자격 확인 한 문장.
   - 링크 한 줄: 청약홈 입주자모집공고 원문 · 공식 분양 일정
   - 링크 한 줄: `브동산 웹사이트에서 전체 분석 보기`(해당 글 URL).
- 이미지는 절대경로 URL + `style="width:100%;height:auto;display:block"`, figure `margin:22px 0`.
- 무순위·공공분양 등 특수 공고도 같은 틀에 맞추고, 무순위 세대 목록·자격·계약금 조건 같은 정보는 표를 하나씩 더한다.

## (이전 기준) 2026.11.09 광교 샘플

`gwanggyo-jayeon-centreville-naver.html` — 광교 자연앤 센트레빌. 네이버용 HTML은 **이 파일과 똑같은 양식·구조·서식**으로 쓴다.
차트 3종(평점 비교 / 적정가격 / 위치 개략도)은 `scripts/beodongsan/make_naver_charts.py`의 `chart_a`/`chart_b`/`chart_map`으로 같은 형태로 만든다.

핵심 규칙(샘플에서 읽은 것)
- 상단 주석 메타(slug/title/category/tags) + 바이라인 + h1 + 빈 문단 후 섹션 6개(1 결론부터 · 2 왜 이 가격이 나왔을까 · 3 브동산 한줄평 · 4 최근 분양단지 · 5 분양 사이트 자료 · 6 결론).
- 섹션 1: 도입 → 스탯 박스 3개(적정가격 / 분양가 / 예상 프리미엄+%) → 굵은 3수치 문장 → 조감도+캡션 → **단지 개요 표**(2열: 위치·규모·시행시공·공급 구성·입주 예정·청약 일정·84㎡ 분양가·규제·주의). 어디?/언제?/얼마?/주의 네 줄은 쓰지 않는다(2026.11.15).
- 섹션 2: h3 입지(문단 → 개략도+캡션 → 예정 교통·학교 문단), h3 비교단지(문단 → chart-a+캡션 → 굵은 종합평점 문장 → 가격 표+note → 굵은 적정가격 문장 → chart-b+캡션).
- 캡션은 작은 회색 non-bold. `이미지 NN` 번호 캡션은 섹션 5에서만 01부터 연번(섹션 1·2의 이미지 캡션에는 번호 없음).
- 섹션 5는 **이미지만 한 번에**(위치도 → 조감도 → 배치도 → 동호수 배치도 → 평면도 → 특수 타입 평면도 → 청약 일정 이미지) 이어 붙인다. 사이에 h3·설명 문단·표를 넣지 않고 짧은 `이미지 NN · 종류` 캡션만 둔다. 설명은 맨 아래 `정리` 한 곳에 간단히(타입별 분양가 표 + 요약 한두 문단). 개요 표는 섹션 1로 올렸으므로 섹션 5에는 두지 않는다(2026.11.15).
- 인포그래픽(차트 3종·일정)은 흑백 바탕에 **포인트 색 황동 `#C8A45C`**(쇼츠·클립·릴스 영상과 통일, 2026.11.15): SITE 막대·적정가격 막대·프리미엄 박스 테두리·SITE 마커·일정 점. `make_naver_charts.py`의 `ACCENT`.
