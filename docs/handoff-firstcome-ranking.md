## 2. 실행 방법

```bash
cd scripts/firstcome
python3 firstcome_engine.py                       # → result2.json + 콘솔에 계산 과정
export RANK_DATE=2026-12-01                       # 회차 기준일 (slug·본문 날짜가 자동으로 바뀐다)
python3 build2.py out                             # → out/<slug>.html, out/<slug>-naver.html, out/<slug>-naver-tags.txt
python3 chart2.py out/chart-top30.png             # 사이트용 차트
python3 chart_m.py result2.json out               # 네이버용 chart-m-1~3.png
```

- slug는 `sudogwon-firstcome-top30-YYYYMMDD`로 자동 생성된다(1회차만 예외: `-202611`). `RANK_SLUG`로 덮어쓸 수 있다.
- 필요한 것: matplotlib, Noto Sans CJK 폰트(`/usr/share/fonts/opentype/noto/NotoSansCJK-*.ttc`). 폰트 경로가 다르면 chart*.py 상단을 고친다.
- `images.json`이 같은 폴더에 있으면 build2.py가 단지별 조감도·위치도를 넣는다(5번 참고).

## 4. 모형 규칙 (엔진에 구현됨)

**기본 (브동산 모형, `beodongsan-realestate-post` 스킬과 동일)**
- 평점 100 = 입지 40(교통 20 + 편의 10 + 교육 10) + 브랜드 20 + 상품성 40
- 평점보정 = 1 ± 점수차 × 0.01 (±20% 한도)
- 연령보정(수도권 상한 1.2): 0~10년은 1 + 개월/120 × 0.08, 10~20년은 1.08 + (개월−120)/120 × 0.12, 20년 초과는 1.2
  - 기준 시점은 대상 단지의 준공(입주) 월이다.
- 적정가 = 비교단지 2곳 보정가의 평균
- 6-1 마피 조정 (선분양 단지만):
  - raw가 −1.5억~−1.0억이면 +3천만원
  - raw가 −1.0억~0이면 절반으로
- 표기: 십만원 단위 반올림 → 만원. 1억 이상은 X.XX억

**미분양 선착순용 보정 (2026-11-16, Paul 피드백 "미분양인데 +1억은 말이 안 된다"에서 나온 규칙)**

| 규칙 | 내용 | 엔진 필드 |
|---|---|---|
| 실질 분양가 | 확정 페이백·입주축하금을 차감 (예: 오목천역 더리브 84㎡ 1억 + 이자지원 1천만) | `benefit`, `benefit_src` |
| 준공 단지 | 자기 단지 실거래·시세를 적정가로. 6-1 조정 안 함 | `own`, `own_src`, `done=True` |
| 미분양 상한 | 주변에 먼저 나온 미분양·마피 단지의 현재가가 천장이다. 새 단지 점수가 더 낮을 때만 평점보정으로 낮추고, 연식 가산은 하지 않는다 (Paul 브레인시티 규칙) | `CEIL`, `ceil` |
| 재검토 트리거 | +5% 초과 또는 −20% 미만이면 비교단지부터 다시 고른다. 그래도 +면 계약금(분양가 10%)을 상한으로 둔다 | 코드 + 사람 판단 |
| 비교단지 선정 | 같은 동·지구의 10년 이내 신축이나 분양권을 쓴다. 다른 생활권의 역세권 대장이나 20년 넘은 구축만으로 비교하지 않는다. 신축이 없으면 `warn`에 하향 편향 가능성을 적는다 | `l5`, `warn` |

## 5. 이미지 — 단지별 조감도·위치도 (1회차 미완)
