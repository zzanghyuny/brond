# 광고 레이더 — 분양 광고로 미분양 선착순 단지 찾기 (2026.11.27 Paul 지시)

네이버 메인 배너·검색광고·분양 광고 기사에 나오는 단지는 대부분 미분양 선착순(줍줍) 단지다. 권역 회차와 줍줍찬스가 이 단지들을 놓치지 않도록 후보 출처로 쓴다. 첫 사례: 네이버 메인 배너의 '효성해링턴 플레이스 군산'(권역 데이터에 없었음).

## 1. 후보 출처 (권역 회차마다 + 제보가 올 때마다)
1. **Paul 제보** — 배너·광고 스크린샷을 보내면 바로 처리한다(아래 3).
2. **분양 광고 기사** — 최근 30일, `선착순 동·호지정`, `선착순 계약`, `계약금 정액제`, `잔여세대` + 권역/시·도 이름으로 뉴스 검색. 'AD'·'분양 관계자' 표기 기사가 대부분 분양 광고다.
3. **검색광고·블로그** — 다음 검색(`https://search.daum.net/search?w=fusion&col=blog&q=<지역 선착순 동호지정>&sort=recency`)과 같은 키워드의 검색광고 문구.
4. 직전 회차 목록·아파트투유·분양노트(기존 출처)와 합쳐 중복을 지운다.

## 2. 확정 기준에 추가 (c)
- 기존 (a) 공식·분양 홈페이지에 선착순 동·호 지정이 떠 있음, (b) 최근 1개월 상담사 영업 글에 더해
- **(c) 최근 30일 안에 분양 측 광고(배너·검색광고·광고 기사)가 선착순·잔여세대·계약금 정액제를 내걸고 집행 중이면 확정.** 근거와 날짜를 기록한다.
- 무순위·임의공급, 오피스텔·도시형, 84㎡·59㎡ 둘 다 없는 단지는 기존대로 제외(주상복합 아파트는 포함).

## 3. 줍줍찬스에 먼저 올리기 (적정가 계산 없이)
1. `python3 scripts/jupjup/applyhome.py <단지명 키워드>`로 청약홈 공고를 찾고, 공고 상세(공급위치·세대수·홈페이지)와 모집공고문 PDF(`pdftotext -layout`)에서 세대수·입주 예정·84㎡(없으면 59㎡) 타입별 공급금액 범위를 읽는다.
2. `scripts/jupjup/extra_sites.json`에 단지를 추가(권역 rid, 대표 타입 최고가, 범위, 확인 근거 `confirmed`), `points.json`에 사실 장점 2~3줄, `notices.json`에 모집공고·홈페이지를 넣는다.
3. `python3 scripts/jupjup/build_jupjup.py` → push. 광고 문구(입주축하금·계약금 0원 등)는 공식 자료로 확인되기 전에는 '확인된 혜택'에 넣지 않는다.
4. 다음 권역 회차에서 적정가까지 계산해 랭킹에 넣으면 권역 데이터가 extra_sites를 대신한다(같은 key를 쓴다).
